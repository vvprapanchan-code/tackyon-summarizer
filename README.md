# 🚀 TACKYON - The AI Summarizer

Welcome to **Tackyon**, a professional-grade Python application designed for high-efficiency content summarization and unique cultural integration.

## ✨ Key Features
* **AI Summarization:** Quickly condense long text and files into key insights.
* **Thirukural Integration:** Unique access to ancient Tamil wisdom through built-in Thirukural verses.
* **Auto-Dubbing:** Innovative audio features for accessibility and ease of use.
* **Polished UI:** A clean, professional interface for a seamless user experience.

## 🛠️ Tech Stack
* **Language:** Python
* **Data:** JSON (Thirukural database)
* **Design:** Professional UI Branding
